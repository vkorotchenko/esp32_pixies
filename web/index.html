Device admin

Checking admin session…

Lighting is available to your trusted network. Wi-Fi, restarts, resets and updates need admin access. One 30-minute session per device; a new login signs out the old session.

Create your first admin password while connected to the protected Pixies hotspot. Its unique Wi-Fi key is shown over USB serial, not on this page. You can then join your home network or keep using the hotspot.

A fresh little spark

Firmware —

Upload the app-only firmware.bin built for esp32s3_n16r8. The website updates with it. Not a merged image, bootloader, partitions or filesystem. Keep this page open; LEDs pause during writing.

Waiting for the device's OTA slot size.

A completed transfer is not a verified boot. This page waits for a new boot ID and running version. No signed-firmware, HTTPS or automatic boot-rollback guarantee. Retain USB recovery.

Under the fairy lights

Status is refreshed every 4 seconds. Polling pauses during uploads; transfer progress comes from your browser.

A deliberate fresh start

Wi-Fi reset preserves admin and lighting. Factory reset erases saved lighting, networks and admin. Both require confirmation.

If locked out, use the documented USB recovery procedure. There is no universal admin password.

Local by design. Trusted network only. This device uses HTTP: passwords, admin requests and uploads are not encrypted in transit. The hotspot is password-protected; keep the LAN trusted. Do not port-forward Pixies to the Internet. No cloud, no external assets, no browser-stored passwords or tokens.
